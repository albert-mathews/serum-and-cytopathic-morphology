Project overview
We need independent expert descriptions of light-microscope images (phase contrast) of Vero E6 cell cultures (ATCC CRL-1586). Prefer freelancers with direct experience culturing or imaging this line or closely related Vero lines. The labeled images will be used to train and evaluate AI vision systems.

Image set structure
You will review micrographs from two separate cell cultures (Culture A and Culture B). Each culture was maintained and imaged on days 1, 2, 3, 4, and 5 (day = day after the experimental passage). Images are phase contrast at 10x or 20x magnification (see scale bar in each image). Images will be grouped by culture and day so you can use day-to-day continuity within each culture.

Scope of work  
1. For each image, write a professional morphology description based only on what is visible and your cell-culture / microscopy experience with adherent monolayers such as Vero E6 (e.g. monolayer integrity, confluence/density, cell shape, rounding, detachment, debris, vacuolation, overall culture appearance).  
2. If you believe you have seen this dataset before, please do not apply — prior familiarity would unblind the task and does not meet the project criteria.

Skills required  
- Hands-on mammalian cell culture experience, ideally including Vero E6 (ATCC CRL-1586) or other Vero / epithelial-like lines  
- Routine use of light / phase-contrast microscopy for adherent monolayers  
- Ability to describe cell morphology in clear scientific language  
- Careful, consistent work on a fixed image set (remote)

Deliverables  
1. Per-image morphology description for every image (structured file or form as agreed: e.g. spreadsheet or document with image ID, day, culture A/B, text description).  
2. Brief note of experience level relevant to this task (years in culture/microscopy; main cell systems; whether you have worked with Vero E6 / ATCC CRL-1586).  
3. Delivery within the agreed timeline; questions only via the Kolabtree workspace.

Commercial terms  
Fixed fee / hard cap as agreed in the proposal; no open-ended hours without a written change order.

Out of scope  
- Image processing, AI model training, or statistical analysis  
- Co-authorship or public attribution (unless separately agreed in writing)  
- Access to information about the dataset beyond what is provided here

Note  
This is paid expert annotation for research/AI evaluation. Deliverables are professional observational descriptions, not clinical diagnoses or endorsement of any scientific conclusion. Client will not publicly identify the expert in publications; please do not publicly associate yourself with Client’s papers unless Client agrees in writing.
