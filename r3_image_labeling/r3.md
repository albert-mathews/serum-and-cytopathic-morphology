# R3 — Human labeling of CRO culture images (research stream)

**Folder:** `r3_image_labeling/`  
**Role:** Extend morphology labeling of CRO phase-contrast images (serum-only arms) beyond the subset labeled by the CRO.

---

## Snippets (paper-ready prose)

**Purpose:** Carefully worded sentences/paragraphs for later drafting. Prefer these over improvised strong language.  
**Rules:** Blinding first. Do not prime labelers with CPE/virus thesis language. Morphology descriptions ≠ etiologic diagnosis.

### R3-S1 — What human labels can support

> Independent, blinded morphology descriptions of phase-contrast monolayers can test whether observers report CPE-like features in cultures that differ only in serum/enrichment and **lack** a viral inoculum. Labels are evidence about **visible culture state**, not about particle composition or clinical infection.

### R3-S2 — Blinding / framing guardrail

> Labelers receive images only—no experimental arm, FBS percentage, or hypothesis. Task language stays descriptive (monolayer integrity, rounding, detachment, debris, vacuolation, confluence). Virus/CPE/Isolation interpretive vocabulary is reserved for analysis after unblinding, not for the rating brief.

# Blinded human labeling — research brief (2026-07-22)

## Protocol intent (authoritative for outreach)

| Parameter | Decision |
|-----------|----------|
| **Blinding** | Labelers must **not** be told culture conditions (e.g. FBS % / Path A vs Path B), inoculum status, or experimental hypothesis. |
| **Task framing** | Images only. Describe what is visible from **professional experience** with mammalian cell culture / light microscopy. |
| **Bias control** | Do **not** prime with CPE / “viral” / Isolation vocabulary in the task brief. Avoid CLSI Table 7 list as a forced checklist if that re-inserts CPE language; prefer open-ended morphology + optional neutral structured fields (confluence, monolayer integrity, rounding, detachment, debris, vacuolation, etc.) chosen carefully. |
| **Stated purpose to labelers** | Labeled images will be used to **train/test AI vision systems** (true and non-leading regarding experimental arms). |
| **Dataset** | ~111 EXP-stage phase-contrast TIFFs (~9 MB each); 22 already CRO-labeled; ~80 unlabeled primary targets. |
| **Preferred rater profile** | People who routinely view **live / unstained / phase-contrast mammalian monolayers** (cell culture techs, RA/scientists, in vitro cell biologists). **Not** default clinical radiologists; clinical pathologists only if they also have culture-monolayer experience (histology WSI ≠ phase-contrast culture). |
| **Design for paper** | Prefer **≥2–3 independent raters** + inter-rater reliability; keep conditions coded offline; no condition leak via filenames. |

### Suggested outreach pitch (short, debiased)

> We need independent expert descriptions of mammalian cell-culture microscope images (phase contrast) for an AI vision training/evaluation dataset. You will receive images only—no experimental metadata—and should describe morphology as you would from professional practice (e.g. monolayer quality, cell shape, confluence, debris, detachment). Work is remote, paid, fixed set of ~80–110 images, with optional second pass for inter-rater consistency. Images will train/test AI vision systems.

Do **not** mention: virus, CPE, FBS arms, Isolation interpretive framing, paper thesis, or CLSI “cytopathic” framing in the initial hire brief.

### Pilot design (before full ~80)

| Step | Detail |
|------|--------|
| Sample | 10–15 images, balanced later by condition offline (raters never see balance rule). |
| Deliverable | Free-text morphology paragraph + optional neutral structured fields + confidence. |

- **Pass 2 headline:** both IRs mark more CPE-type morphology in Culture B (2% FBS) than Culture A (10% FBS). Shared B>A item: ballooned/enlarged (binary κ 0.45). Other items agree poorly (e.g. cell death 14% agreement); IR2 additionally marks degeneration, syncytia and cell death in B and lowers "healthy overall" in B, while IR1 marks all images healthy and carries its B excess on cytoplasmic strands. Several items are saturated for one or both raters; `cpe_detected` is true on all 100 images for both.
- **Instrument effect:** IR2's Pass 1 free text showed only a small B−A difference; the Pass 2 checklist elicited a large one (IR1 showed the same pattern on a smaller scale).
