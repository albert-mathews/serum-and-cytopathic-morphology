# C080 — data schema and extraction notes

**Claim.** C080 (Observation, CLAIMS.md): *The Isolation/titration endpoint is the least reproducible of the
methods compared.*

**Purpose.** `C080.csv` is the machine-readable extraction backing C080. One row per first-class
Isolation/titration panel that reported **both** a cell-culture/infectivity endpoint and a molecular (or
antigen) endpoint on the same known-positive material, so the two endpoints can be compared head-to-head.
Rows are drawn from `p7_repeatability_corpus.csv`, filtered to first-class Isolation rows where both
endpoints were reported.

## Column headings (exact order)

| # | Column | Meaning | Allowed values / notes |
|---|--------|---------|------------------------|
| 1 | `panel_id` | the P7 corpus row id | `P7-###` (matches `p7_repeatability_corpus.csv`) |
| 2 | `source_ref` | short citation | author + journal + volume:page |
| 3 | `pmid` | PubMed ID | integer; `(no DOI; journal)` where PMID cell should hold no value — see `doi` |
| 4 | `doi` | full DOI | full DOI string; `(no DOI; Can J Vet Res)` where none exists |
| 5 | `year` | publication year | integer |
| 6 | `domain` | human / veterinary | `human`, `veterinary` |
| 7 | `endpoint_class` | which Isolation-linked endpoint | `isolation_cpe` (CPE/Isolation read), `titer` (infectivity titration) |
| 8 | `n_labs` | participating labs (or labs attempting the endpoint) | integer; for P7-001 this is total labs (40), isolation attempted by 18 |
| 9 | `cell_culture_endpoint` | how the cell-culture result was actually read | free text (e.g. "virus isolation in MDCK", "virus infectivity (HAD50/TCID50)") |
| 10 | `cc_metric` | what was measured for the cell-culture endpoint | `sensitivity`, `detection probability`, `DD50 range`, `low-titre isolation rate` |
| 11 | `cc_value` | the cell-culture endpoint value | number or range, as printed |
| 12 | `molecular_endpoint` | how the molecular/antigen result was read | free text (qPCR, RT-PCR, antigen ELISA) |
| 13 | `mol_metric` | what was measured for the molecular endpoint | `sensitivity`, `detection probability`, `DD50 range`, `reliable` |
| 14 | `mol_value` | the molecular endpoint value | number or range, as printed |
| 15 | `ratio_cc_to_mol` | the comparison verdict | `cc_less_sensitive` (cell-culture worse than molecular) — the only coded value so far |
| 16 | `blinding` | whether labs were blind to sample identity | `blind`, `blind_by_design`, `not_blind` |
| 17 | `blinding_stated` | whether the source states blinding in words | `yes`, `no` (i.e. "blind"/"randomized"/"anonymity" appears vs implied only) |
| 18 | `serum_disclosed` | serum/medium stated at the scored step | `yes`, `no`, `partial` |
| 19 | `notes` | free text | caveats, denominators, verbatim anchors |

## Extraction method

1. **Row eligibility.** A panel is eligible only if (a) its `endpoint_class` in `p7_repeatability_corpus.csv`
   is `isolation_cpe` or `titer` AND (b) the source reports a molecular/antigen comparator on the same samples.
   Serology-only or molecular-only panels are excluded from C080 (they belong to C081 / the secondary tier).
2. **Value fidelity.** `cc_value` and `mol_value` are copied verbatim as printed (ranges where the source gives
   a range). No recomputation, no rounding beyond what the source printed. When the source states a qualitative
   comparator ("reliable", "robust") rather than a number, that word is used and the numeric bound (if any) goes
   in `notes`.
3. **Blinding coding.** Read the Methods for any of: "blind(ed)", "randomized/randomised", "anonymity/anonymized",
   "coded code number". Explicit word present → `blinding_stated = yes`, `blinding = blind`. If the design is an
   EQA/proficiency panel scored against a withheld reference but no such word appears → `blind_by_design`,
   `blinding_stated = no`. If the source says the material was *known to contain virus* → `not_blind`.
   **This column is the load-bearing one for the C080→C151 argument and is not inferred.**
4. **Serum disclosure.** `yes` if the source names FBS/serum % at the scored step; `partial` if it names the
   dilution medium but not the maintenance serum; `no` if neither.
5. **The `ratio_cc_to_mol` field is the claim's operative column.** It records, per panel, whether the
   cell-culture endpoint underperformed the molecular comparator. A value other than `cc_less_sensitive` would
   be a potential refiner/counterexample and must be flagged in `notes`.

## Adjacent corpus (not in C080.csv — extends p7_repeatability_corpus.csv)

C080 is strictly **Isolation/titration vs molecular**. Six further ring trials were added to the stream corpus
in 2026-11-12 (P7-012..P7-017) but are **not** in `C080.csv` because they are antigen/molecular/serology, not
virus isolation. The most relevant to C080/C081 is **P7-012 (Gourlaouen 2020, rabies)**, which shows the
*human-microscopy-read* fluorescent-antibody (DFA) test underperforming molecular RT-PCR (87.69% vs 98.2%
concordance). That isolates the **visual-readout/operator-judgment** component of the C080 asymmetry from the
cell-culture propagation component — the same human-vs-machine contrast that also characterizes CPE reading.
See `p7.md` and `p7_repeatability_corpus.csv` rows P7-012..P7-017.

## The blinding question (why it matters, and the current answer)

See `p7.md` → "Interpretive note — how C080 threads through R1–R3" and the C080 entry in `CLAIMS.md`.

The short version: the panels are **heterogeneous** in blinding, and the two that *are* explicitly blinded
(Goodell P7-004; plus Onyilagha P7-011 in the secondary tier) still show the cell-culture endpoint underperform
the molecular comparator. The decisive case is **P7-008 (Olesen 2022), which is NOT blind** — the labs knew the
material contained virus — and yet qPCR reached 0.96–1.0 while cell-culture infectivity reached only 0.68–0.90.
That is: an unblinded lab reproduces the genetic readout and still fails the cell-culture readout. The asymmetry
is therefore **not** an artifact of blinding.

**Detection vs assembly (Albert, 2026-11-12 — do not truncate the genetics toolchain).** In these panels
"molecular" means **detection** (qPCR/RT-PCR against a known target). That is **not** a limitation of C080's
relevance to P3 — detection is one side of the viral-genetics toolchain, assembly is the other, and **without
detection, assembly is far less useful (especially in virology)**. C080 establishes that the *detection* layer
is reproducible across labs while the *Isolation/titration* (phenotype) layer is not. The *assembly-level*
non-determinism that C151 predicts (reference-prior-driven assembly, consensus construction, database ontology)
is a **separate seam** — the P3 A3 / same-stock assembly probe — not a reason to discount C080. Both the
detection layer and the assembly layer are in scope for P3; C080 documents the former, C151 predicts the latter.
