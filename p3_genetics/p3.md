## 1. What P3 is

**Working label:** sequence inheritance / reference circularity (genetics layer).

If Isolation under dual media (growth ~10% FBS → maintenance ~1–3% / 2% FBS) + CPE does not specifically detect a discrete viral agent, then:

1. Historical **Isolates** are culture products of **unknown particle composition** (not proven pure virion preparations by the Isolation endpoint alone).
2. Characterization that rests on those Isolates—including **sequencing and database deposition**—**inherits** that under-determination.
3. Later work that uses the same Isolation-style methods and matches public “viral” references can **reaffirm** prior labels or add **new** labeled entries without independently grounding a second particle class.

**P3 is a logical risk / prediction branch**, not a result already shown by the Vero E6 CRO experiment.

---

## 2. Motivation from the particle layer

Under the FBS-dominant model, matched **± inoculum** cultures (same cell line, FBS/maintenance, time, purification) should yield **similar** products on:

| Already emphasized (P1 / EV) | Natural extensions |
|------------------------------|--------------------|
| Mass, volume, density | Size distribution, particle count, zeta potential |
| Morphology (EM) | Cryo-EM / AFM, flow-virometry |
| Chemistry (protein, etc.) | Proteome, lipidome, glycome |

**Nucleic acids** are the parallel cargo prediction:

- If purified particles are the same host-derived population, **particle-associated** RNA/DNA profiles should be highly similar ± inoculum.
- Bulk cell RNA-seq is a **weaker** prediction (inoculum matrix can change host transcription without a virion).

### If particle RNA-seq *differs* ± inoculum

Candidate explanations (not mutually exclusive):

1. **Inoculum carryover / passive NA** (adsorb, co-sediment; no replication required).
2. **Reference / database mis-allocation** (hits labeled “viral” because earlier Isolates were so labeled).
3. **Host, bovine (FBS), or reagent NA** with uneven filtering.
4. **Non-deterministic pipelines** (library prep, host subtraction, assembly cutoffs, DB choice, e-values).
5. **Matrix-driven change in host EV cargo** (still not a second particle *class*).
6. **True inoculum-linked genome** with replication controls (harder for pure host-EV story; still does not restore CPE specificity).

**Discussion leaning (session):** for *labeling* and literature lock-in, **database circularity** is a primary structural concern; for a single differential experiment, **carryover + host/bovine cargo + pipeline** may be more immediate than DB error alone.

## 3. The circularity engine

```text
Confounded Isolation (FBS↓ + inoculum)
  → CPE → “Isolate”
  → purify / sequence culture product
  → deposit as viral reference
  → next study: similar methods, BLAST / primers / classifiers vs that reference
  → “confirmation” or “new virus/strain”
  → database grows
```

Two failure modes:

- **Reaffirmation:** new Isolate matches old reference → looks like independent validation (may be shared culture product + shared label).
- **Novelty inflation:** no match → “new virus” → new error node in the reference graph.

No conspiracy required: non-specific culture detector + non-discriminating purification + sequence-as-identity + databases that store labels as ontology.

## Genetics beyond current P3 (open extensions)

This section records **inquiry seeds** Albert requested beyond the parked Step 1 + Step 5 core. It describes Isolation practice / particle co-purification / sequence inheritance risk. Claims are limited to what the cited corpus documents; these items are **not started** as formal streams.

### A1. ±inoculum / mock sequencing (Step 4)

**Prediction (Albert’s original).** If culture + CPE is treated as a non-specific warrant for labeling culture products “viral,” then matched **negative-control cultures**—identical ingredients, including sputum/matrix when used, same cells, same maintenance/serum, same purification and bioinformatics pipeline, **minus** the claimed inoculum—should **sometimes** yield the same “viral” contigs (or the same classifier calls against culture-derived references) as the +inoculum arm.

**If the prediction fails** (sick/inoculum-only genetics under a transparent, pre-registered pipeline), fork among at least:

1. **Sick-only / inoculum-linked source genetics** — the contig really tracks the added material.
2. **Pipeline subjectivity / prior-driven parameters** — host filters, reference DBs, assembler/k-mer choices, abundance cutoffs, or “viral” classifiers that encode Isolation-era labels.
3. **Understanding too weak** — design, depth, or particle vs bulk mismatch insufficient to test the warrant.
4. **Culture+CPE non-specificity claim wrong** (for that system) — Isolation endpoint really was virus-specific there.

**Distinguish product classes:**

| Product | What is sequenced | What a shared contig would mean |
|---------|-------------------|----------------------------------|
| **Bulk cell RNA-seq / culture supernatant RNA** | Cellular + media + any particle cargo | Label may reflect culture-system transcriptome, not a purified virion |
| **Particle-associated NA** (pellet / density / size-selected) | NA co-purifying with the particle fraction used for “virus” work | Stronger test of particle–label linkage; still inherits purification overlap (P2) |

**Gold 4a vs pragmatic 4b:**

- **4a (gold):** Matched ±inoculum, same matrix/FBS/cells, particle purification on both arms, classification **with and without** viral reference DBs, pre-registered thresholds, blanks/reagent controls.
- **4b (pragmatic):** Literature and public SRA re-analysis of mock / uninfected / medium-only runs already paired with Isolation papers; document whether “viral” calls appear under the paper’s own pipeline story.

**Inquiry seed, not a completed experiment.** A positive hit on mocks supports culture/process/DB origin of the label; a clean inoculum-only result pressures the non-specificity warrant for that system without automatically repairing CPE as a general detector.

### A2. FBS contig audits

**Yes — in scope as an open extension.** Audit contigs and classifier hits from:

- Sequencing **FBS alone** or FBS lots used in Isolation media;
- **Uninoculated** medium–serum controls (cells ± serum, no claimed inoculum);
- **Reagent / kit blank** hits reported in metagenomic contamination literature;
- **Isolate papers’ supplemental contig tables** that already list bovine / host / reagent hits beside the “viral” assembly.

This is **not** a Step 1 origin/type census. It asks whether culture-system ingredients and supplements contribute sequences that Isolation pipelines can label viral when references were themselves culture-derived. Report prevalence and provenance language; do not smuggle a global database ontology verdict.

### A3. Same stock, different assemblies

**Question:** When a **named stock / Isolate / accession lineage** is re-sequenced years or groups apart, how much do published assemblies differ (length, gene content, consensus polymorphisms, “complete genome” boundaries)?

**Why it matters for inheritance:** If “the” genome is unstable across passage + assembler priors, the public object looks less like a fixed natural particle genome and more like a **culture-product consensus** shaped by lab history and pipeline choices. If assemblies are tightly reproducible across independent groups under stated methods, that constrains (does not eliminate) the culture-consensus reading.

**Empirical sketch:** Pick named type/prototype stocks with ≥2 independent assembly publications; tabulate year, lab, passage notes, technology, assembler, and diff metrics; separate biological change (passage adaptation) from bioinformatic disagreement where papers allow.

### A4. Adversarial clinical-direct + particle + infectivity (keep hard cases)

**Do not bury hard cases.** Rows and papers that claim **clinical-direct** sequence (no culture), or that combine particle assays with infectivity readouts, stay in the adversarial balance set.

**Score the infectivity warrant explicitly.** If “infectivity” is operationalized as **CPE / plaque / TCID50 / MOI in culture**, triangulation still **rests on the culture foundation** that R1–R2 interrogate. Code the stack honestly, for example:

| Layer | Example warrant | Inheritance note |
|-------|-----------------|------------------|
| Sequence | Clinical amplicon / mNGS contig | May still classify via culture-derived references |
| Particle | EM / density / marker panel | Overlap with EVs (P2) unless class-separating |
| Infectivity | CPE, plaque, TCID50, culture MOI | Culture-endpoint dependent unless a non-culture infectivity assay is stated |

Keep the papers; do not re-label them as settled independent proof without stating which layers still route through Isolation culture.
