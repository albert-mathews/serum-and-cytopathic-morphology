## Step 1 — Origins of sequences for common named viruses (PRIMARY for Point 1)

### Constraints
- **No phage** (out of scope entirely).
- **No HIV** for now.
- Prefer **original discovery / first-deposit papers** and later **confirmation / re-sequencing deposit** papers — not GenBank metadata keyword mining as the main warrant.
- Families to start: measles, poxviruses, coronaviruses, poliovirus/enterovirus, adenovirus, cytomegalovirus; expand to other common named human viruses after the spine is solid.

### Method
1. For each virus (or type strain / early reference genome): identify **first public sequence paper(s)** and accession lineage (who deposited what, when).
2. Read Methods: was the sequenced material from **cell culture**, was **CPE** (or equivalent culture morphology) used to assert the Isolate, was the sequence taken from that Isolate?
3. Map **subsequent confirmation deposits** the same way (re-sequences, “complete genome” updates, vaccine-strain sequences, etc.).
4. Score culture-CPE path: yes / no / unclear / not applicable (e.g. clinical direct with no culture).

### Target claim (if supported)
Most or all origin + confirmation deposit papers for these common named viruses used cell culture ± CPE-derived material → public viral sequence ontology for those names is, in practice, culture-linked.

### Honest caveat (methods, not cynicism)
Peer review and GenBank deposit rules have **not** always required unambiguous culture/CPE documentation. Expect many “unclear” rows; do not invent Methods. Unclear ≠ culture; unclear = gap.

### Sample size
Per-family deep dives first (quality). Aggregate n across families toward **≥100 deposit-events** (origin + confirmation papers) for a “representative of common named viruses” claim — see Step 2a note.

## Step 4 — Matched genetics / contig comparison (Point 4)

### 4a — Ideal design papers
Studies with **same cell system, same purification, same pipeline, ± inoculum / mock / uninfected**, comparing “viral” contig calls. Gold standard; expect rare.

### 4b — Pragmatic surrogate (user preference)
- Viral Isolate→sequence papers with **supplemental contig lists**
- EV / uninoculated-culture sequencing papers with supplemental contigs
- Compare overlap / shared “viral-like” hits carefully (same taxa? host? bovine? reagent?)

**Naive risk (real):** different chemistries, hosts, subtractors, databases, and years make naive contig identity comparisons misleading. Mitigate by: same cell line when possible, same era/pipeline family, protein-level not only nucleotide, and treating overlap as **hypothesis-generating**, not proof of identity.

Both 4a and 4b are useful; 4a is decisive when found, 4b is broader.
